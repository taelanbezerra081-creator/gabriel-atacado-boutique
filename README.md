# Gabriel Atacado Boutique

Portfólio independente do site de moda feminina no atacado da Gabriel Atacado Boutique.

**Prévia do site:** https://id-preview--509144e8-7319-47ab-80bf-678dee2df9c1.lovable.app  
**Editar no Lovable:** https://lovable.dev/projects/509144e8-7319-47ab-80bf-678dee2df9c1

## Projeto

Este repositório contém o código-fonte do site criado no Lovable: catálogo de moda feminina, categorias, filtros, páginas de privacidade e termos, e contato via WhatsApp.

## Executar localmente

Requer Node.js e Bun (ou npm). Instale as dependências e execute `dev` no `package.json`.

## Mídia

O código foi exportado do projeto, mas a integração disponível não exportou as imagens binárias originais em `src/assets/`. Para executar localmente com todas as fotos, copie as imagens do projeto Lovable para os caminhos referenciados no código.
